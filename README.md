Post Manager App adalah sebuah solusi manajemen konten desktop yang dirancang untuk menjembatani interaksi antara pengguna dan server melalui antarmuka yang intuitif dan responsif. Aplikasi ini bukan sekadar alat CRUD biasa, melainkan sebuah studi kasus implementasi Pemrograman Visual yang menggabungkan estetika desain dengan performa komputasi yang efisien.

Project ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Visual dengan tujuan mempelajari:

Aplikasi terhubung dengan API berikut:
Base URL: https://api.pahrul.my.id/api

OperasiMethodEndpoint

Tampilkan semua post: GET/api/posts
Detail satu post: GET/api/posts/{id}
Tambah post baru: POST/api/posts
Edit post: PUT/api/posts/{id}
Hapus post: DELETE/api/posts/{id}
